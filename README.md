# Single-Cell RNA-seq Reanalysis: IFN-β Response in PBMCs

## Project question

How does IFN-β (interferon-beta) stimulation alter transcriptional programs
across different PBMC (peripheral blood mononuclear cell) populations?

This is a reproducible reanalysis of an already-processed single-cell
RNA-seq perturbation dataset - not a from-scratch pipeline starting from
raw sequencing reads.

## Dataset

Kang et al. 2018 (Nature Biotechnology), PBMC control vs. IFN-β
stimulated, loaded via pertpy.dt.kang_2018(). Source: GEO GSE96583.

- 24,673 cells x 15,706 genes as distributed
- Two conditions: control / stimulated (roughly balanced)
- Includes pre-existing cell_type labels, used strictly as a validation
  reference - clustering and marker-based annotation are performed
  independently first (see 04_clustering_annotation.ipynb).

## Methodology

01 - Ingestion: load the Kang 2018 dataset via pertpy; confirm cell/gene
counts and condition/cell_type label distributions.

02 - QC: inspect the AnnData object (X, layers, obs, obsm, raw) before any
transformation. Mitochondrial genes are absent from this processed release
(documented limitation). Cells filtered on min_genes=200; genes on
min_cells=3. Result: 24,673 -> 24,562 cells, 15,706 -> 15,701 genes.

03 - Preprocessing: normalize_total + log1p, 2000 HVGs selected, scaled,
PCA (20 PCs chosen from the variance ratio elbow), neighbors graph, Leiden
clustering (resolution=1.0) -> 18 clusters.

04 - Clustering annotation: each of the 18 clusters scored against 8
canonical PBMC marker gene sets to propose an identity, then compared
against the dataset's existing cell_type labels as a validation check.
Most clusters agree; disagreements (cluster 6 NK/CD8T ambiguity, cluster
13 megakaryocyte vs CD4T) and low-confidence clusters (17: erythrocyte
contamination; 10, 14: housekeeping genes) are discussed explicitly.

05 - IFN-β differential expression: stimulated vs. control compared within
each proposed cell type (Wilcoxon test). Canonical interferon-stimulated
genes (ISG15, MX1, IFIT1, IFIT3, STAT1, IRF7, etc.) checked for recovery.
Response magnitude (number of significant DE genes) ranked by cell type;
shared vs. cell-type-specific response genes identified.

## Main findings

- Independent clustering and marker-based annotation largely recover the
  dataset's original cell type labels (agreement in the large majority of
  the 18 clusters), validating the reanalysis pipeline.
- Canonical interferon-stimulated genes are recovered in the stimulated
  vs. control comparison across most PBMC cell types, confirming the
  differential expression pipeline captures genuine IFN-β biology.
- Response magnitude and specific response genes vary by cell type,
  consistent with cell-type-specific interferon signaling.

## Limitations

- Mitochondrial-based QC was not possible: mitochondrial genes are absent
  from this processed dataset release.
- UMAP visualization was skipped due to a torch/sympy package conflict
  encountered in the Google Colab environment used for compute-heavy
  steps; this does not affect clustering (Leiden) or differential
  expression, neither of which depends on the UMAP embedding.
- This is an educational reanalysis, not a validated clinical or
  diagnostic result.
